# 本机环境坑（Windows + WorkBuddy 沙箱）

> 这些坑**只在特定机器/沙箱出现**，但每次出现都会浪费 30 分钟以上。
> 提前知道 = 直接绕开。

---

## 坑 1：Glob 工具有索引盲区 ⭐ 曾导致严重误判

**现象**：Glob 工具在 `C:/Users/lenovo/Desktop` 搜索返回 **0 命中**，
据此误判"源数据不在本机"，向用户报告"无法重跑，需要你本机跑"。

**真相**：数据**一直在**，就在 Desktop 那个长中文路径下。
改用 **Bash `ls` / `find`** 一次就找到。

```bash
# ❌ Glob 搜不到
# ✅ 用这个
ls "C:/Users/lenovo/Desktop/"*/"2 - C 题：城市绿色物流配送调度/"
find /c/Users/lenovo/Desktop -iname "*.xlsx" 2>/dev/null | head
```

**教训**：
1. **找文件优先用 Bash `ls`/`find`，不要只信 Glob**
2. 报告"数据不存在"这种**阻塞性结论**前，至少用两种独立方法验证
3. 更重要的：按用户约定，**遇阻塞先停下来问，不要默默转向做别的事**

## 坑 2：venv 路径因 junction 迁移而变

WorkBuddy 数据已通过 Windows Junction 迁到 D 盘，venv 实际位置也变了：

```
❌ C:/Users/lenovo/.workbuddy/binaries/python/envs/default/bin/python.exe
✅ D:/WorkBuddyData/.workbuddy/binaries/python/envs/default/Scripts/python.exe   ← Windows 用 Scripts/
✅ C:/Users/lenovo/.workbuddy/binaries/python/envs/default/Scripts/python.exe     ← 也能用
```

**注意**：Windows 下是 `Scripts/python.exe`，**不是** `bin/python`（那是 Linux 路径）。

**本任务需要的包**：`numpy` `pandas` `matplotlib` `openpyxl` `python-docx` `pypdfium2` `pypdf`

**坑**：直接用 `python` 命令（系统 Python 3.12）没有 `docx` 模块。
**必须显式写 venv 的完整路径**。

## 坑 3：`results_cache.pkl` 导致"改了代码但结果没变"

**现象**：改了 `solver.py` 的收敛记录逻辑，重跑 `run_all.py`，拿到的还是旧曲线。

**根因**：`run_all.py` 检测到 `results_cache.pkl` 存在就**只加载不重算**。

**修法**：
```bash
rm -f results_cache.pkl      # 强制重算（建议先备份）
python bench_solve.py        # 先估耗时，避免盲开长任务
python run_all.py            # 首次 ~10.5 min，二次 ~6 min
```

**反向利用**：只想改图不想重跑 GA 时，直接读缓存即可（省 6 分钟）：
```python
import pickle; res = pickle.load(open("results_cache.pkl", "rb"))
```

## 坑 4：glob 跨目录误覆盖同名文件

**事故**：扫 `AI工具使用详情.pdf` 时，glob 匹配到**另一日期旧工作区（2026-07-29）的同名文件**
并覆盖掉了刚生成的新文件。

**修法**：
- 拷贝/覆盖前**必须确认候选就是目标文件**
- **收窄 glob 范围**，不要用 `D:/WorkBuddyData/**` 这种广撒网

## 坑 5：CJK 文本提取不可靠，核验要用别的手段

**现象**：本沙箱里从 PDF 提取中文文本会缺字/乱序，据此判断"文件没更新"是错的。

**可靠的核验手段**：
| 验什么 | 用 |
|--------|-----|
| PDF 页数 / 书签 / 文件名 | **pypdf outline**（可靠） |
| docx 里的文件名/文本 | **document.xml 原文**（可靠） |
| 视觉版式 | LibreOffice 转 PDF → pypdfium2 渲染 PNG |
| ❌ 不要只信 | CJK 文本提取 |

## 坑 6：safe-delete 机制会拦截删除

**现象**：`os.remove('论文_定稿版.docx')` 被 genie-trash 拦截，报
"Some operations were aborted"。

**修法**：不删，直接写新文件名。**删除用户文件必须经用户确认**（用户明确约定）。

## 坑 7：沙箱联网拉包会卡死

**现象**：`build_pdf.sh` 里的 `mpm.exe --set-repository` 联网在沙箱里卡死 12 分钟。

**修法**：移除了联网步骤的版本。反正 basic-miktex 已装好所需包，缺包时再手动补。
