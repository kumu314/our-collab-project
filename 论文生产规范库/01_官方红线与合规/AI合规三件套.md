# AI 合规三件套（缺一即可能取消资格）

> 官方《人工智能工具使用规定》要求。三件**同时**具备，缺任何一件都属于材料不全。

---

## 件套 1：正文逐处标注

**要求**：AI 参与的每一处都要标注，**不能只在附录笼统说一句**。

**本次做法**：在「三、模型建立」3.1 节前插入说明块：

```markdown
> 按《全国大学生数学建模竞赛人工智能工具使用规定》，如实声明：
> 本队在建模思路、程序实现与文字组织环节使用了人工智能工具辅助，
> 具体工具信息见参考文献 [5]，使用情况详见支撑材料《AI 工具使用详情》。
> 全部数值结果由本队程序独立运行产生，已人工复核。
```

**注意**：
- 不要写"（本模拟为流程演练…）"这种自曝练习稿的话 → 直接删
- 声明块用引用块 `>` 排版，视觉上独立

## 件套 2：参考文献条目

**格式**：`[编号] 工具名（用途），版本/型号，开发机构，使用日期`

**本次**：
```markdown
[5] WorkBuddy（人工智能辅助写作与代码工具），版本 2026.09，Tencent，2026-09-03。
```

**注意**：
- 工具名用**正式名**，不要带昵称（"WorkBuddy（小羽）" → "WorkBuddy"）
- 编号要与正文引用、参考文献列表连续一致

## 件套 3：《AI 工具使用详情》PDF

### 硬性要求
| 项 | 要求 |
|---|------|
| 文件名 | 必须是正式名，**禁止**出现「占位」「流程演练」「示例」「草稿」 |
| 篇幅 | 1 页 A4，可打印签字 |
| 编译 | 独立 `.tex` 用 xelatex 编译（fontspec `SimSun[BoldFont=SimHei]` + geometry 页边距） |
| 位置 | 随支撑材料提交，同时在附录 §8.1 文件列表里列出 |

### 必填字段
- 参赛队号 ← **人工填**
- 队员姓名 ← **人工填**
- 队员签名 + 指导教师签名 ← **手写，AI 不能代填**
- 工具名称 / 版本 / 开发机构
- 使用环节（据实写：建模思路、程序实现、文字组织…）
- 独立性声明

### 生成脚本
`make_ai_decl_pdf.py`（reportlab + 内置 STSong-Light 中文字体）或独立 `.tex` + xelatex。

## 五、踩过的坑

1. **原文件名带"占位"二字**（`AI工具使用声明_占位.pdf`），且正文也写了"占位" → 等于告诉评委没交真实材料。必须改名 + 改正文 + 重出 PDF/docx。
2. **glob 跨目录误覆盖**：扫文件名时匹配到**另一日期旧工作区的同名 PDF**（2026-07-29 的 `AI工具使用详情.pdf`）并覆盖新文件。
   → **拷贝/覆盖前必须确认候选就是目标文件，收窄 glob 范围。**
3. **核验不要只信 CJK 文本提取**（本沙箱不可靠）。用 **pypdf outline**（可靠）+ **docx document.xml 文本**（可靠）双核验文件名与页数。
