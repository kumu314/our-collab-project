# 论文禁用词与不当内容黑名单

> **起因**：2026-09-03 用户反馈「这一点为什么会有工作区和文件位置这种根本不能在论文中出现的东西？？还有其他地方也存在不应出现的内容吗？」
> 根因：并行工作流模拟时，把**内部协作痕迹**直接写进了论文正文。
> **原则：论文是给评委看的独立作品，任何"我们怎么做出它"的过程信息都不属于论文。**

## 四、项目符号：黑点 → 数字

用户明确要求："这种黑点符号不要再用了，用数字代替"

`03_流水线与脚本/scripts/bullets_to_numbers.py` 把 `- ` 改成 `1. 2. 3.`

**关键例外**：模型假设 H1–H8 这类**本身已带编号**的条目，再套 `1. **H1**` 会重复编号 → 改为去符号独立成段、段间空行。

**只处理代码块之外**（用 `infence` 标记跳过 ` ``` ` 围栏内的行，否则会破坏代码）。

实测：`论文_定稿版.md` 36 个 `- ` → 0；`_pdf.md` 39 个 → 0，编号项 57 个。

## 五、源码里的不当内容（同样要清）

`solver.py` / `run_all.py` 里也要扫，因为**附录会把源码全文印进论文**：

| 位置 | 原内容 | 改法 |
|------|-------|------|
| docstring | `Author: code-hand sub-agent...` | 改成中性描述 + "All numerical results ... are reproducible" |
| 硬编码路径 | `OUT = "D:/WorkBuddy_output/数模并行工作流/sim"` | `OUT = os.path.dirname(os.path.abspath(__file__))` |
| 硬编码数据目录 | `desktop = "C:/Users/lenovo/Desktop"` | 相对搜索 `./data` → 脚本目录 → cwd → 父目录 → `CUMCM_DATA_DIR` 环境变量 |
| 注释 | `# 0. Assumptions (documented; stated in code_results.md)` | `# 0. Model assumptions and parameters (see Section 2 of the paper)` |

**换机可运行性**：相对路径 + 环境变量兜底，评审在别的机器上也能跑通。
