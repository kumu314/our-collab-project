# 法证型审计（数字对账）

> **这是最后一道关。** 交付前必须把论文里每个数字和求解器输出对账。
> 跳过 = 埋雷。评委抽查一个数字对不上，整篇论文可信度归零。

---

## 一、为什么叫"法证型"

不是"读一遍觉得没问题"，而是**逐条取证**：
- 论文里出现的**每个关键数字**，都要能在权威数据源里找到同源值
- 找不到的 = 手抄 / 估算 / 编造，**必须修**

---

## 二、权威数据源（唯一真源）

| 数据 | 来源文件 | 说明 |
|------|---------|------|
| 各问题总成本、车辆数、碳排放 | `numerical_results.md` | 求解器输出 |
| 敏感性分析数值 | `numerical_results.md` | — |
| 路径序列 | `routes_p1.txt` | — |
| 图上的量 | 对应 PNG（但**图注要说清是哪个量**） | — |

**原则**：数字只能从这些地方**取**，不能从论文 A 处抄到 B 处（抄错会连锁）。

## 三、对账脚本

```python
# audit_numbers.py
import pathlib, re

# 1) 从权威源读真值
TRUTH = {
    "P1总成本":       76832.06,
    "P2总成本":       77367.24,
    "P1新能源车":     11,
    "P2新能源车":     15,
    "P1碳排放kg":     4189.49,
    "P2碳排放kg":     4207.87,
    # ... 从 numerical_results.md 逐条抄
}

paper = pathlib.Path("论文_定稿版.md").read_text(encoding="utf-8")

bad = 0
for key, val in TRUTH.items():
    s = f"{val:.2f}" if isinstance(val, float) else str(val)
    hits = paper.count(s)
    ok = hits >= 1
    if not ok: bad += 1
    print(f"{key:16s} {s:>12s}  出现 {hits} 次  {'OK' if ok else '❌ 缺失'}")

print("\n结论:", "全部对账通过" if bad == 0 else f"{bad} 项对不上")
```

## 四、比数字更重要的：口径审计

数字对上了但**口径不对**更致命。逐条问：

| 检查项 | 问自己 |
|--------|-------|
| **假设 vs 代码** | H1…Hn 每一条，求解器实现是不是真的这样？ |
| **图注 vs 图** | 图注描述的量，是不是图上画的那个量？ |
| **正文 vs 数据文件** | 正文数字与 `numerical_results.md` 同源吗？ |
| **附录代码 vs 磁盘代码** | 附录印的是不是真实跑的那份？ |
| **口径一致性** | "98 客户"和"88 有效客户"全文是不是统一口径？ |
| **异常值** | 异常（车型3 实启 0 辆、收敛曲线平）有没有主动交代？ |

## 五、真实审计案例（本次演练）

### 案例 1：假设与代码矛盾（方法论硬伤）
- **发现**：H2 写"需求不可拆分"，但求解器实际是 SDVRP（允许拆分）
- **佐证**：单客户最大需求 12198 kg ≫ 3000 kg 车容，物理上必须拆分
- **判定**：模型描述与代码矛盾 = 硬伤，必改
- **修法**：H2 改为允许拆分，约束 (10) 由 `Σy=1` 放宽 `≥1`，3.2.2 / 4.2 节说明解码器按容量分包

### 案例 2：大 M 污染统计（数值硬伤）
- **发现**：P2 第 2 代种群均值 = **22301506**（2200 万）
- **根因**：`decode` 中"客户放不下"返回的大 M 惩罚 `1e9+sum` 被算进均值（1e9/45 ≈ 2.2e7）
- **后果**：纵轴被撑到千万量级，真实下降被压成直线
- **修法**：`conv_mean.append(mean([c for c in costS if c < 1e8]))`（只统计可行个体）
- **修后**：P1 80185→79657（降 527），P2 81654→81308（降 346），0 离群点

### 案例 3：收敛曲线是水平线（呈现层，但要主动交代）
- **发现**：P1 收敛值恒 76832.06，81 点 0 代下降
- **根因**：`convergence` 只记"严格更优"的 running-best，而初始种子（角度序+贪心最大车型）已是全局最优
- **处理**：不掩盖。改画种群均值（有下降），虚线标最优值，正文主动解释"构造式初始化有效"
