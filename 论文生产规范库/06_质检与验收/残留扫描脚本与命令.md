## 一、一键全检（复制即用）

```bash
cd 项目目录

echo "=== 1. 不当内容（必须 0）==="

echo "=== 2. 身份泄漏（必须 0，合规红线）==="
grep -nE "河南财经|河财|本校|我校|指导老师|队员" "$MD"

echo "=== 3. 黑点项目符号（必须 0）==="
grep -cE "^- " "$MD"

echo "=== 4. Figure 英文前缀（必须 0）==="
grep -cE "Figure [0-9]+:" "$MD"

echo "=== 5. 图表编号分章（应 = 图数+表数）==="
grep -cE "^!\[图[0-9]+-[0-9]+" "$MD"
grep -cE "begin\{center\}表[0-9]+-[0-9]+" "$MD"

echo "=== 6. 引用格式（禁 xxx.png）==="
grep -nE "见 [a-z_]+\.png" "$MD"
```

**1–4 必须全部 0 命中；5 的计数要与论文实际图表数一致；6 必须 0。**

## 五、双版本一致性（PDF 有的版式，Word 必须有）

| 要求 | PDF 实现 | Word 实现 | 检查 |
|------|---------|----------|------|
| 摘要+关键词独占一页 | `\newpage` + 去 `--toc` | `fix_docx_pagebreak.py` 插 `w:br type=page` | 转 PDF 看第 1 页 |
| 图/表题注居中 | `\begin{center}` | `fix_docx_alignment.py` 后处理 | 段落 `w:jc=center` |
| 图下去 Figure 前缀 | caption 包 `labelformat=empty` | pandoc 原生不带前缀 | grep `Figure [0-9]+:` |
| 代码高亮多色 | `\AtBeginDocument{\lstset}` | 代码附录独立 docx（6 色） | 渲染 PNG 目视 |
| 代码有边框 | `frame=single` | tblBorders sz=12 / 666666 | 查 XML |

> **教训**：早期 `build_docx.sh` 漏调 `fix_docx_pagebreak.py`，
> 导致 Word 版没分页符、摘要没独占首页。**PDF 有的版式要求，Word 必须逐一对应实现。**

## 六、批量替换脚本的写法约定

```python
RULES = [
    ("分类", "旧文本", "新文本"),
    # ...
]

for name, path in FILES:
    t = open(path, encoding='utf-8').read()
    for cat, old, new in RULES:
        n = t.count(old)
        if n:
            t = t.replace(old, new)
            print(f'  [{name}] {cat}: 已替换 {n} 处')
        else:
            print(f'  [{name}] {cat}: ⚠️ 未命中')
    open(path, 'w', encoding='utf-8').write(t)
```

**关键点**：
1. **逐条回报命中/未命中**（"已替换 N 处" / "⚠️ 未命中"）
2. **每份文件分别打印**（两份 md 内容可能已经不同步）
3. 新增规则只改 `RULES` 列表，不动逻辑

实测效果：`论文_定稿版.md` 58238→57800 字符（15 命中 / 2 未命中）；
`_pdf.md` 58491→58038（16 命中）。未命中的 2 条据此手工补做。
