## 一、正文篇幅（硬线）
- [ ] 正文（摘要 → 参考文献）= ____ 页，**≤ 上限**（官方默认 20 页，若用户拍板其他值需注明）
- [ ] 附录（支撑材料 + 源码）= 第 __–__ 页（官方不限）
- [ ] 页数是**出 PDF 后实测**的，不是估的

## 二、标题与结构
- [ ] 顶级标题用中文数字：一、二、三…八、
- [ ] 章序：摘要 → 一、问题重述 → 二、模型假设与符号说明 → 三、模型建立 → 四、模型求解 → 五、结果与分析 → 六、模型评价与改进 → 七、参考文献 → 八、附录
- [ ] 子节用 1.1 / 2.1 / 3.1 形式，全局唯一
- [ ] 摘要后有「关键词」，且**独占一页**

## 三、图表
- [ ] 编号分章：`图X-X` / `表X-X`
- [ ] 图在下、表在上
- [ ] 题注居中（PDF 和 Word **两版都居中**）
- [ ] 图下无 `Figure N:` 前缀
- [ ] 轴标签 / 图例 / 标题全部中文
- [ ] 正文引用写「如图 X-X 所示」「如表 X-X 所示」
- [ ] **对比图有视觉对比度**（差值 <5% 时改用三幅子图方案）

## 四、AI 合规三件套
