## 一、PDF 链路（官方提交件）

```bash
bash build_pdf.sh
```

内部四步：
1. 清理 PATH 里的 `python.exe` 文件型条目（**不清理 MiKTeX 直接崩**）
2. `python prep_pdf_md.py` → 生成 `论文_定稿版_pdf.md`（修字形三坑）
3. pandoc + xelatex 编译
4. 输出 `论文_定稿版.pdf`

**验收**：
- 日志里 `Missing character` 必须是 **0**
- 出现 `PDF_DONE`
- 文件大小正常（本次 ~908 KB / 40 页）

> ⚠️ 若已经手工改过 `论文_定稿版_pdf.md` 且不想被覆盖，直接跑 `bash build_pdf.sh`（它不调 prep）。
> 但**常规流程请保持 build_pdf.sh 内含 prep**，避免漏预处理。

## 二、Word 链路（审稿用，6 步）

```bash
bash build_docx.sh
```

| 步 | 命令 | 作用 |
|---|------|------|
| 1/6 | `make_docx.py` | 生成 `论文_定稿版_docx.md` + `docx_center_list.txt`（居中清单） |
| 2/6 | 可写性探测 | 锁住就改输出名 `_论文_定稿版_新.docx` |
| 3/6 | `pandoc ... -t docx` | 转 docx（`--syntax-highlighting=tango`） |
| 4/6 | `fix_docx_alignment.py` | 图本体 / Image Caption / 表题 → 居中 |
| 5/6 | `fix_docx_pagebreak.py` | 关键词后插分页符（摘要+关键词独占一页） |
| 6/6 | `make_code_appendix_docx.py` | 独立代码附录 docx |

**验收输出**（本次实跑）：
```
图片段居中 = 5
题注样式段居中 = 5
清单精确匹配居中 = 3
已在「关键词： 绿色物流；…」后插入分页符
solver.py: 475 lines (after clean)
run_all.py: 269 lines (after clean)
```

> **步骤 5 是后来补的**：早期 build_docx.sh 漏调 `fix_docx_pagebreak.py`，
> 导致 Word 版页码比 PDF 少一页、摘要没独占首页。
> **教训：PDF 有的版式要求，Word 版必须逐一对应实现，不能只顾一边。**
