## 二、口径（★ 先统口径，再算数）

| 口径项 | 采用值 | 说明 / 冲突点 |
|--------|-------|--------------|
| 运动阶段 | 题面四阶段＝①**弹射加速（＝火箭马达推力段，t∈[0,5s]）** ②自由上升 ③自由下落 ④开伞匀速落地 | ✅ 题面原文：第一阶段即"受到火箭马达推力作用，向上加速"，**题面未列独立导轨段** |
| 导轨（弹射筒）段 | **不单独建模**；其效果以 `v_e` 作为 t=0 初始速度赋予 | 行程 ~1.05–1.6 m、历时 ~0.13 s，占 5 s 推力段 2.6%；题面无此段。推导见 `docs/decisions-2026-09-04.md` |
| `v_e` 的性质 | t=0 的**初始条件**（相对飞机，沿导轨方向），不是独立运动阶段 | 题面"弹射初始速率"；物理来源＝弹射筒出口速度 |
| 坐标系（地面系） | 原点取 t=0 导轨出口投影；x 正向=飞机前进方向，y 向上。地面系初速 $\vec v(0)=(v_0-v_e\sin\beta,\; v_e\cos\beta)$ | ✅ |
| 坐标系（飞机随体系，H7/H8 判据用） | 原点取导轨出口；$s$ 轴**指向机尾为正**，$y$ 轴竖直向上；$s(t)=x_{plane}(t)-x_{pilot}(t)$ | ✅ 见 `docs/decisions-2026-09-04.md` §2.3 |
| 5g 约束的适用段 | **仅约束火箭马达推力段（t∈[0,5s]）的合成加速度** | ⚠️ 导轨段过载文献值 12–20g，属座椅既定装备参数（DRI 指标评定），不参与本题优化。**论文须主动声明此区分** |
| 弹射方向 | 沿导轨，导轨与竖直方向夹角 **β=15°，向机尾（x 负向）倾斜为正** | ✅ 文献区间 13°–20°（科普中国·高过载座舱），β 进敏感性 |
| 推力模型 | 火箭推力 T 沿导轨方向，持续 **t1 = 5 s**（题面固定），随后无推力 | ✅ 题面 |
| 推力优化目标 | 在全部安全约束下求**最小推力 T_min**；并求该推力下允许的**最低飞行高度 h_min** | ✅ 建模手拍板 |
| 气动阻力 | 二次阻力 F = ½ρ·CdA·v² 全程作用，风向忽略；ρ 常数（海拔修正做敏感性） | ✅ 标准默认 |
| 生理限制 | 过载 ≤ **5g**；无氧面罩时**绝对高度 < 3000 m** | ✅ 题面；救生伞文献"表定开伞高度 3000 m"与氧限互证 |
| 开伞条件 | 人椅下降中 **\|v\| ≤ 97 m/s（=350 km/h 开伞硬指标）** 触发开伞；开伞点高度须留 **≥100 m** 充气裕量；伞后终端速度 **v_t = 6 m/s** 匀速落地 | ✅ 采购硬指标 + 救生伞稳降 6–7 m/s 文献 |
| 碰撞判据 | **看垂尾**（不是整机身长）：人椅经过垂尾纵向区间 $s\in[s_{vt},L_{plane}]$ 时，须有 $y>h_{vt}$ | ✅ 垂尾是最高最靠后的障碍物，文献"垂尾可比座舱导轨高 5–6 m" |
| 灼伤判据 | 尾喷流锥：顶点 $(s=x_{exh},y=-\Delta y_n)$，轴沿 +s（机尾），半顶角 $\alpha$，长度 $L_{flame}$；轨迹不得落入锥内 | ✅ 推力方向（沿导轨，偏 β）与喷流方向（沿机身轴）**属两个物体，无需一致**；但 β 向机尾倾会增大灼伤风险，是 Q2 的代价项。公式见 `docs/decisions-2026-09-04.md` |
| 参照机型 | F-16 级单发轻型战斗机（机长 15.03–15.06 m 文献一致） | ✅ 正文声明为参数假设 |
