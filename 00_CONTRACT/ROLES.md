# 角色分工（ROLES）

> 三人协作的唯一身份表。你的**分支名、产出目录、看板条目**都从这张表来。
> 认领角色 = 在自己那一行填上姓名和 GitHub 账号，提 PR 合入。先到先得。

## 角色表

| 角色 id | 职责 | 认领人 | GitHub 账号 | 状态 |
|---------|------|--------|------------|------|
| `coder` | 建模 / 求解 / 出图 / 出表 / results.json | 建模手 | kumu314 | ✅ 已定 |
| `writer` | 按模板写章节稿 / 图表题注 / 参考文献 | 待认领 | | ⬜ 待认领 |
| `captain` | 契约 / 假设 / 符号 / 统稿 / 合 PR | 待认领 | | ⬜ 待认领 |

## 规则（硬性）

1. 分支名只用 `agent/<角色id>/<任务>`，角色 id 只能是上面三个之一。
2. 产出只落在 `01_OUTBOX/<角色id>/`，不碰别人的目录。
3. `00_CONTRACT/`、`scripts/`、`.workbuddy/`、`.github/` 只有 captain 能改。
4. 认领任务 = 把任务行从「待认领」整体搬到自己的分区（见 STATUS.md）。
