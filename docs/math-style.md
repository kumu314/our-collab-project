# 数模文风与去 AI 痕迹指南

> 给 writer 的硬规则。三个 agent 自由发挥 = 三种风格 = 统稿全靠人肉对齐。这套规则把风格锁死。

## 一、文风基调
- 毛主席文风：通俗易懂、字字千金、客观中立，不带政治正确堆砌。
- 让数字说话，少用"显著的""极大的"这类形容词。
- 敢下判断："这个方案不好，因为…"而非永远"各有优劣"。

## 二、禁用套话（出现即改）
值得注意的是 / 不难看出 / 综上所述 / 随着…的不断发展 / 标志着 / 彰显了 / 充分体现了 / 不言而喻 / 显而易见

## 三、去 AI 痕迹
- 禁用膨胀句式、-ing 尾巴、testament to 等英式腔。
- 长句拆短句，一句话只说一件事。
- 段落长短交替（别每段一样长，那是机器感最强的地方）。
- 隐藏人格：不写"作为 AI / 我们来…"这类自我指涉。

## 四、段落与列表
- 段落 3–5 句为主，刻意长短交替。
- 真正的并列项才用 `1. 2. 3.`，不用 `-` 黑点（数模规范禁用黑点编号）。
- 编号：图 `图X-X` / 表 `表X-X`，分章编号。

## 五、数字与引用
- 一切数字用 `{{占位符}}`，不手抄（见 SPEC.md 第三节）。
- 图引用写「如图 X-X 所示」，禁写「见 xxx.png」。
