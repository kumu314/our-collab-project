## 一、运动方程（地面惯性系）

状态 $\mathbf{X}=(x,y,v_x,v_y)$，$x$ 沿飞机前进方向，$y$ 竖直向上，原点取 t=0 时导轨出口在水平面的投影、$y=h_0$ 为弹射高度。

$$\begin{cases}
\dot x = v_x,\quad \dot y = v_y\\[4pt]
\dot v_x = -\dfrac{\rho C_dA}{2m}\,|\mathbf v|\,v_x+\dfrac{T(t)}{m}(-\sin\beta)\\[8pt]
\dot v_y = -\dfrac{\rho C_dA}{2m}\,|\mathbf v|\,v_y-g+\dfrac{T(t)}{m}\cos\beta
\end{cases}$$

- $|\mathbf v|=\sqrt{v_x^2+v_y^2}$，空气静止（无风，H3）
- 推力沿导轨方向（向机尾偏 $\beta$），$T(t)=T$ 当 $t\in[0,t_1]$，$t_1=5$ s；其后为 0
- **推力方向在地面系固定不变**（H2 补充：假定稳定伞/陀螺使座椅姿态保持，不考虑翻滚）

**初值（t=0）**：
$$x=0,\quad y=h_0,\quad v_x=v_0-v_e\sin\beta,\quad v_y=v_e\cos\beta$$

> 导轨（弹射筒）段不单独积分，$v_e$ 直接作为 t=0 初始速度（依据见 `docs/decisions-2026-09-04.md`）。

## 二、飞机随体系与安全判据

$$s(t)=v_0t-x(t)\quad(\text{人椅落后飞机的纵向距离，机尾方向为正}),\qquad y_{rel}(t)=y(t)-h_0$$

### 判据 1｜不撞垂尾（H7）
人椅经过垂尾纵向区间 $s\in[s_{vt},\,L_{plane}]$ 时须高于垂尾顶：
$$y_{rel}(t)\ge h_{vt}\quad\Rightarrow\quad \text{vt\_clear\_min}=\min_{s\in[s_{vt},L_{plane}]}\big(y_{rel}(t)-h_{vt}\big)>0$$

### 判据 2｜不被尾喷流灼伤（H8）
$$\text{灼伤}\iff x_{exh}\le s\le x_{exh}+L_{flame}\ \land\ |y_{rel}+\Delta y_n|\le (s-x_{exh})\tan\alpha$$
$$\text{burn\_clear\_min}=\min_{x_{exh}\le s\le x_{exh}+L_{flame}}\Big(|y_{rel}+\Delta y_n|-(s-x_{exh})\tan\alpha\Big)>0$$

### 判据 3｜生理过载（H4）
座椅传递给飞行员的加速度（**不含气动风阻减速**）：
$$\frac{T}{m}\le 5g\quad\Rightarrow\quad T\le T_{\max}=5gm=8339\ \mathrm{N}$$

> **为什么不含风阻**：$v_0=250$ m/s 时气动减速约 $18g$，是高速弹射的固有环境载荷，由头盔/面罩/束缚系统承担（文献：600 kt 时肢体风阻载荷可超 40g）。题面 5g 指"未穿抗G服"的**持续性**耐受，对应火箭推力的持续加速段。**论文须主动声明此口径。**

### 判据 4｜氧气（H5）
$$\max_t y(t) < h_{ox}=3000\ \mathrm{m}$$

### 判据 5｜开伞（H6）
下降段速度达**触发速度** $v_{open}=45$ m/s 时开伞，随后以 $v_t=6$ m/s 匀速落地；
开伞点须留 $h_{margin}=100$ m 充气裕量（即开伞瞬间离地高度 ≥ 100 m）。
$v_{open}^{max}=97$ m/s（350 km/h）作为**结构允许的最大开伞速度**校验（本模型下必然满足）。

> ⚠️ **为什么触发速度不能取 97**：本参数下自由下落终端速度
> $v_{term}=\sqrt{2mg/(\rho C_dA)}=58.3$ m/s $<97$ m/s → 下降段**永远达不到 97**，伞永远不开，模型失效。触发速度必须低于终端速度。

### 判据 6｜不撞地
开伞—减速—匀速全过程在 $y>0$ 内完成。

## 三、优化问题表述（Q1：水平飞行）

**决策变量**：推力 $T$（连续）；飞行高度 $h_0$ 作为**情景参数**，基准取 $h_0=1500$ m（仅用于画图与对照，Q1 核心输出是 $h_{\min}$；见第五节决策 3）。

$$\text{s.t.}\quad \text{vt\_clear\_min}>0,\ \ \text{burn\_clear\_min}>0,\ \ T\le T_{\max},\ \ \max y<3000,\ \ \text{开伞与落地可行}$$

**两者存在反向耦合（本题的核心张力）**：
- 推力 $T$ 越大 → 上升越高 → 下落行程越长 → **开伞所需的最低飞行高度 $h_{\min}$ 反而越小**（离地更安全）；
- 但 $T$ 越大 → 过载越大、火箭越大、峰值越高（受 5g 与氧限挤压），且尾喷灼伤风险上升。

即存在**双目标权衡**：目标① 推力 $T$ 尽量小（省能量、低过载、低灼伤风险）；目标② $h_{\min}$ 尽量大（离地安全裕度高）。二者冲突，无法同优。

> **h_min 计算口径（决策补充，对应 coder 反馈①）**：
> $h_{\min}$ 是**推荐工作点 $(T^*, h_0=1500)$ 下自由飞行段（开伞前）的轨迹最低海拔**，直接由 ODE 积分取 $\min y(t)$ 得到，是一个定值（≈$h_0+600\sim700$ m，由先升约 739 m 再降到开伞 $v=45$ m/s 的飞行动力学决定）。
> **不要把 $h_0$ 扫描的下限当成 $h_{\min}$**——$h_0$ 是情景参数（基准 1500 m），Q1 在固定工作点算 $h_{\min}$。
> 开伞点按判据 5 在**下降段速度达 $v_{open}=45$ m/s 时**计算（**不要在顶点开伞**）；该最低点由飞行动力学自然决定，无需额外地面约束去"卡"它。

### 「最佳推力」定义（建模手已拍板，决策 2）
**给出 $T$–$h_{\min}$ 帕累托前沿，并取膝点作为推荐工作推力。**
1. 在 $T\in[T_{req},\,T_{\max}]$ 上 dense sweep（建议 ≥200 点），逐点算 $h_{\min}(T)$；
2. 前沿即 $\{(T,\,h_{\min}(T))\}$；作图 `fig5-1_T_vs_hmin.png` 作为 Q1 主图；
3. **膝点选取**：以"最劣角" $(T_{\max},\,h_{\min}(T_{req}))$ 为参考，取前沿上**归一化距离最远**的点作推荐推力 $T^*$：
   $$\max_{T}\ \frac{T-T_{req}}{T_{\max}-T_{req}} + \frac{h_{\min}(T)-h_{\min}(T_{req})}{h_{\min}(T_{\max})-h_{\min}(T_{req})}$$
   （兼顾"电机小"与"离地高"，取边际收益开始变平的拐点。）
4. 论文同时报告 $T_{req}$（下界）与 $T_{\max}$（5g 上界），并讨论 $\beta$ 对前沿的影响（Q2 衔接）。

## 四、建模手数值预演（写代码前已完成，供 coder 对照量级）

纯 Python RK4，dt=0.002 s，参数取 FACTS v2.1。

### 4.1 基准参数下**无解**（重要）
取 $h_0=1500$、$v_0=250$、$v_e=16$、$\beta=15^\circ$、$h_{vt}=5.5$ m：

| 量 | 值 |
|---|---|
| 越过垂尾所需最小推力 $T_{req}$ | **14360 N** |
| 5g 允许上限 $T_{\max}$ | 8339 N |
| 结论 | ❌ **无解**：$T_{req}>T_{\max}$ |

### 4.2 根因：垂尾高度取值过高
$h_{vt}=5.5$ m 来自科普文章"垂尾可比座舱导轨高 5–6 m"的粗估，**与机型硬数据不符**：

| 依据 | 数值 |
|---|---|
| F-16 全机高 | 4.88 m（militaryfactory / armedforces.eu）、5.09 m（科普中国） |
| 座舱栏杆距地（估算） | ≈1.2–1.5 m |
| **垂尾顶高出导轨出口** | **≈3.4–3.7 m** |

→ **取 $h_{vt}=3.5$ m**（有硬数据支撑）。

### 4.2b 修正后复核（$h_{vt}=3.5$ m，$h_0=1500$ m，$v_0=250$，$v_e=16$，$\beta=15^\circ$）

| 量 | 值 |
|---|---|
| $T_{req}$（垂尾余量 ≥0.5 m） | **2520 N** |
| $T_{\max}$（5g） | 8339 N |
| $T_{\max}$（氧限，峰值<3000 m） | 33489 N |
| **可行推力区间** | **$T\in[2520,\ 8339]$ N → ✅ 有解** |

| $T$ (N) | 垂尾余量 (m) | 喷流余量 (m) | 峰值海拔 (m) |
|---|---|---|---|
| 2520 | 0.50 | 5.08 | 1585 |
| 3000 | 0.60 | 5.20 | 1623 |
| 5000 | 0.96 | 5.69 | 1803 |
| 8000 | 1.46 | 6.38 | 2047 |

### 4.3 修正后的可行域（$h_0=1500$ m，其余不变）

| 参数组合 | $T_{req}$ | 与 $T_{\max}$=8339 比较 |
|---|---|---|
| $h_{vt}=3.5$ m，$v_0=250$ | 2520 N | ✅ 可行 |
| $h_{vt}=3.5$ m，$v_0=200$ | 1000 N（探测下限） | ✅ 可行 |
| $h_{vt}=4.0$ m，$v_0=250$ | 5200 N | ✅ 可行 |
| $h_{vt}=5.5$ m，$v_0=250$（原） | 14360 N | ❌ 无解 |
| $h_{vt}=5.5$ m，$v_0=200$ | 6669 N | ✅ 勉强可行 |
| $v_0=250$，$v_e=24$（三级弹射筒上限） | 4288 N | ✅ 可行 |

### 4.4 其他量级结论
- **氧限不是紧约束**：$h_0=1500$ m 时，氧限允许的推力上限约 33000 N ≫ $T_{\max}$。紧约束是 **5g 上限**和**垂尾间隙**。
- **灼伤判据很宽松**：各工况下喷流余量 5–7 m，自动满足；但要照常检验（低推力工况可能收紧）。
- **$\beta$ 越小越有利**：$\beta=0^\circ$ 时 $T_{req}=8500$ N < $\beta=5^\circ$ 的 9853 N < $\beta=15^\circ$ 的 14360 N。因为 $\beta$ 向机尾倾既削减竖直分量、又把人椅往机尾推。**但工程上座椅须后倾以对齐脊柱受载**，故 Q2 存在"性能 vs 生理"的权衡——这是很好的论文素材。
- **飞行高度量级**：受 3000 m 氧限约束，$h_0$ 必须 ≲2400 m（$h_0=2500$ 时峰值已达 3047 m）。原 FACTS 的 $h_0$ 敏感性区间 [5000,11000] m **完全错误**，已修正为 [300, 2400] m。

## 五、建模手已拍板的决策点（供 coder 直接落地）

1. **$h_{vt}=3.5$ m**（已实施，PR #8 三处修正之一）：取硬数据（F-16 全机高 4.88–5.09 m 减座舱栏杆 1.2–1.5 m），放弃 5.5 m 粗估。模型因此才有解。
2. **「最佳推力」= 帕累托前沿 + 膝点**（决策 2，见第三节）：不取单一极值，给出 $T$–$h_{\min}$ 前沿并取归一化距离最远的膝点 $T^*$ 作推荐工作推力。
3. **$h_0$ 基准值 = 1500 m**（决策 3，已写入 FACTS）：仅用于画图与对照；Q1 核心输出是 $h_{\min}(T)$，敏感性另按 $h_0\in[300,2400]$ 扫描。
